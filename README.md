# boxcraftparty.com

Website for **Box Craft Party**, a crafting game for kids: home page, privacy policy, terms of use and
`app-ads.txt` for AdMob. Served by GitHub Pages at https://boxcraftparty.com.

The privacy policy and terms are generated from the app project (`python3 tools/build_site.py`), so edit them
there and copy the updated files here.
